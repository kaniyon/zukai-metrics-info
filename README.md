# zukai-metrics-info

個人用ツール「Zukai Kobo Metrics」の説明ページとプライバシーポリシー。
Google OAuth 同意画面（外部・本番）の「ホームページ」「プライバシーポリシー」のURLとして使用する。

- 公開URL: https://kaniyon.github.io/zukai-metrics-info/
- ポリシー: https://kaniyon.github.io/zukai-metrics-info/privacy.html
- 対象: YouTubeチャンネル「図解工房」(@zukai_kobo) の運営者本人が使用する内部ツール
- 用途: 自分のチャンネルの YouTube Analytics データ（読み取り専用）を確認し、動画を改善する
- **秘密情報は含まない**（認証トークン・APIキー・生成コードは別の private リポジトリで管理）
